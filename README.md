IT TECHalanay - Event Hub

a streamlined interactive event dashboard built for a tech convention. focused on a clean, robust two-module architecture featuring a Tech Trivia Quiz with custom player names and sorted leaderboards, alongside a MediaDevices Photo Booth with live camera streaming and custom CSS filters. The application runs entirely on the client-side using HTML5, CSS3, Vanilla JavaScript, and Tailwind CSS.

How to Run It

1. Clone or download this repository.
2. Make sure the HTML file is named index.html.
3. Just double-click index.html to open it in any modern browser no backend setup, npm installs, or servers needed!

Tech Stack & Platform Technologies

1. HTML5 & CSS3: Semantic markup and responsive layout styling.
2. Tailwind CSS: Used via CDN for rapid styling, custom dark mode colors, and a modern cyberpunk aesthetic.
3. Vanilla JavaScript (ES6+): Handles all the app state, game loops, DOM updates, and interactivity without any heavy frameworks.

HCI Concepts & Web APIs Used

1. Thoughtful Interaction Design & Usability: Clean tab navigation, visual hover states, instant feedback on quiz answers, and smooth confetti animations when winning prizes.
2. Dynamic DOM Manipulation: Real-time updates for score streaks, active attendee lists, high score tables, and the bug smasher canvas game loop.
3. MediaDevices API (navigator.mediaDevices.getUserMedia): Powers the Photo Booth module so users can stream their webcam live right inside the browser.
4. Web Audio API: Programmatically generates sound effects (beeps and success/error tones) using oscillators so we don't have to deal with external audio files.
5. Responsive Layout: Designed to look good on different screen sizes using flexbox, grids, and Tailwind's responsive utilities.
